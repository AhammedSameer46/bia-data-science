# Machine Learning Notes

## What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed.

Example:
- Email spam detection
- Netflix movie recommendations
- Face recognition
- Self-driving cars

---

## Types of Machine Learning

### 1. Supervised Learning
The model learns from labeled data.

Input → Output

Examples:
- House price prediction
- Student result prediction
- Email spam classification

Algorithms:
- Linear Regression
- Logistic Regression
- Decision Tree"
- Random Forest
- Support Vector Machine (SVM)

---

### 2. Unsupervised Learning
The model learns from unlabeled data and finds hidden patterns.

Examples:
- Customer segmentation
- Market basket analysis

Algorithms:
- K-Means Clustering
- Hierarchical Clustering
- PCA

---

### 3. Reinforcement Learning
An agent learns by interacting with an environment and receiving rewards or penalties.

Examples:
- Game-playing AI
- Robotics
- Self-driving cars

---

## Machine Learning Workflow

1. Collect Data
2. Clean and Preprocess Data
3. Split Data into Training and Testing Sets
4. Choose a Model
5. Train the Model
6. Evaluate Performance
7. Improve and Tune the Model
8. Deploy the Model

---

## Important Terms

### Dataset
A collection of data used for training and testing.

### Features
Input variables used for prediction.

Example:
- Age
- Height
- Weight

### Target Variable
The output the model predicts.

Example:
- House Price
- Exam Result

### Training Data
Data used to teach the model.

### Testing Data
Data used to evaluate the model.

---

## Common Evaluation Metrics

### For Regression
- MAE (Mean Absolute Error)
- MSE (Mean Squared Error)
- RMSE (Root Mean Squared Error)
- R² Score

### For Classification
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
